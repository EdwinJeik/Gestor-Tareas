# Mis tareas (Angular 18)

Gestor de tareas con registro/inicio de sesión, CRUD de tareas, tablero por estado, búsqueda y filtros.

Los datos (usuarios y tareas) se guardan en el `localStorage` del navegador; no hay backend.

## Ejecutar
```bash
npm install
npm start      # http://localhost:4200
npm run build  # salida en dist/tareas-app/browser
```

## Despliegue en Vercel
Importar el repositorio en vercel.com; `vercel.json` ya define el build y la salida.
